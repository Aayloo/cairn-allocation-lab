# Cairn command-center override

## Intent

Use the persisted `Enterprise Gateway` reference only as a high-integrity,
navy-grey starting point. Cairn is an analyst cockpit, not a sales landing page.

## Overrides

- Product mode: dense multi-asset research workspace.
- Background: near-black graphite, with warm limestone accent rather than a
  generic bright green CTA.
- Surface hierarchy: command bar, workspace, evidence card, audit metadata.
- Typography: system sans for interface, restrained serif for editorial
  conclusions, monospace for numbers and provenance.
- Motion: state transitions only; no parallax and no decorative looping motion.
- Primary interaction: command palette (`Ctrl/Cmd + K`) and persistent workspace
  navigation.
- Accessibility: visible focus, 44px controls, reduced-motion support, no
  color-only encoding.

## Anti-patterns

- Marketing hero that hides the actual portfolio.
- Chat-first interface with no deterministic dashboard.
- Fake live-data signals or simulated real-money performance.
- Dense tables without explanatory conclusions.
